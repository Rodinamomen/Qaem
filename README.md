# Qaem — Qiyam Prayer Reminder

A modern Android app that helps you stay consistent with **Qiyam Al-Layl** and **Fajr**. Receive accurate prayer reminders, track your daily commitment, and build lasting spiritual habits with a beautiful, offline-first experience.

---

## Features

### Home
- [ ] Display today's Qiyam & Fajr times
- [ ] Daily commitment tracker
- [ ] Mark today's Qiyam as completed
- [ ] Inspirational Quran verses and Hadith
- [ ] Show current Hijri date

### Prayer Times
- [ ] Calculate accurate Fajr & Qiyam times
- [ ] Automatic location detection
- [ ] Manual location selection
- [ ] Multiple calculation methods

### Notifications & Alarm
- [ ] Reliable Fajr alarm
- [ ] Qiyam reminder notification
- [ ] Alarm works during Silent & Do Not Disturb
- [ ] Snooze support
- [ ] Custom alarm sounds

### Commitment Tracker
- [ ] Daily prayer streak
- [ ] Monthly completion statistics
- [ ] Prayer history calendar
- [ ] Completion percentage

### Settings
- [ ] Light / Dark theme
- [ ] Arabic & English languages
- [ ] Location permission management
- [ ] Notification preferences
- [ ] Alarm configuration

### Share
- [ ] Share the app with family and friends

## Technologies Used

| Technology | Purpose |
|---|---|
| Kotlin | Primary language |
| Jetpack Compose | UI framework |
| Kotlinx Serialization | JSON serialization |
| Supabase | Backend, authentication & database |
| Room | Local database (offline-first) |
| Koin | Dependency injection |
| Navigation | In-app navigation |
| Material 3 | UI components |
| WorkManager | Background reminders |
| Android AlarmManager | Accurate prayer alarms |
| Location Services | Prayer time calculation based on location |
